Desi Delight - Royal Indian Restaurant 

A modern, responsive website for an authentic Indian restaurant featuring royal-themed design and seamless user experience.
🌐 Live Demo
Visit the live website:https://desidelightrest.netlify.app

📋 Project Overview

Desi Delight is a fully functional restaurant website that showcases authentic Indian cuisine with a royal touch. The website features a modern design with elegant purple and gold color scheme, responsive layout, and interactive elements.

🚀 Features

✨ Core Features

•	Responsive Design - Works perfectly on all devices (desktop, tablet, mobile)
•	Interactive Menu - Filter dishes by categories (Appetizers, Mains, Desserts, Drinks)
•	Shopping Cart - Add items, view cart, and checkout functionality
•	Online Reservations - Book tables with date and time selection
•	Contact Form - Get in touch with the restaurant
•	About Section - Learn about the restaurant's story and team

🎨 Design Elements
•	Royal purple and gold color scheme
•	Smooth animations and transitions
•	Interactive hover effects
•	Royal confetti animation on successful orders
•	Elegant typography and spacing
•	High-quality food imagery

🛠️ Technical Features

•	Local storage for cart persistence
•	Form validation
•	Responsive navigation
•	Image optimization and error handling
•	Cross-browser compatibility

🔧 Installation & Setup

1.	Clone or Download the project files
2.	Local Development:
o	Place all files in your web server directory
o	Ensure PHP is enabled for form processing
o	Open index.html in a web browser
3.	Deployment:
o	The project is ready for deployment on platforms like Netlify, Vercel, or any static hosting service
o	For PHP functionality, ensure your hosting supports PHP
